# Snakerito - Next Steps

## Where We Left Off
- Android Studio is syncing Gradle for the first time (downloading dependencies)
- Wait for sync to finish (progress bar at bottom of Android Studio disappears)

## Once Sync Completes
1. Set up a device to run on:
   - Tools → Device Manager → Create Virtual Device → pick Pixel 6 → download API 35 image → Finish
   - OR plug in an Android phone with USB Debugging enabled
2. Click the green play button (▶) in the toolbar (or Shift+F10)
3. The app will build, install, and launch

## How to Play
- Tap to start
- Swipe to change direction
- Eat salsa to grow your snakerito
- Don't hit the walls or yourself!
